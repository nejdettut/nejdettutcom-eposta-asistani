# AI E-posta Asistanı

Konu + alıcı + ton + dil → yapay zekâ profesyonel veya samimi bir e-posta taslağı hazırlar (konu satırı, selamlama, gövde, kapanış, imza).

[nejdettut.com](https://www.nejdettut.com) vitrinde Next.js 16 + Vercel AI SDK + Groq tabanlı bir uygulama.

## Deploy
```
npm install
cp .env.example .env.local   # GROQ_API_KEY
npm run dev
```
